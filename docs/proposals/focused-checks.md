The source guards bind tracked bytes before and after. CI installs only exact Playwright/core 1.65.0 with registry integrity pins in owned runner storage; application dependencies remain zero. Its first manual execution must establish real source connectivity and public-data publication; fixtures and documentation do not substitute for that proof. Source errors leave the previous committed catalogue intact. No raw recipient or concession records are requested.
